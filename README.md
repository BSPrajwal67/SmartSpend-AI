
# SmartSpend AI

### AI-Powered Personal Finance Management System

SmartSpend AI is a web-based application that helps users manage their personal finances using AI-powered transaction categorization and financial insights.

## Features

- Financial dashboard
- Income and expense tracking
- AI-based transaction categorization
- Transaction history
- Expense analytics and charts
- Personalized savings recommendations
- SQLite database integration

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js
- Naive Bayes Machine Learning Algorithm

## Installation

1. Clone the repository:

   git clone YOUR_REPOSITORY_URL

2. Navigate to the project:

   cd SmartSpendAI

3. Create a virtual environment:

   python -m venv venv

4. Activate it:

   .\venv\Scripts\Activate.ps1

5. Install dependencies:

   pip install -r requirements.txt

6. Run the application:

   python app.py

7. Open in your browser:

   http://127.0.0.1:5000
